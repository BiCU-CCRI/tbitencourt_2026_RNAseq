|---|---|---|---|
| *Candida albicans* SC5314 | ASM18296v3 | GCF_000182965.3 | CGD A22-s07-m01-r01 (2022-04-18) |
| *Klebsiella pneumoniae* subsp. pneumoniae MGH 78578 | ASM1630v1 | GCF_000016305.1 | NCBI RefSeq PGAP (2024-03-03) |

## Why this repository includes the exact downloaded NCBI genome/annotation

Depending on the species, NCBI may overwrite annotation files in place at the same accession URL rather than record dated snapshots. The *K. pneumoniae* annotation was regenerated by PGAP on 2025-03-23 (with 14 more CDS than the version used here). Therefore, the exact per-organism assembly/annotation files used for the published analysis are included in this repository.

`bash 01_build_reference.sh` (run from the repository root) builds the combined FASTA/GTF/GFF, the STAR and salmon indexes, and the derived annotation files listed below. The script also checks that the rebuilt salmon index matches the one behind the published analysis (`SeqHash f10eb0891d2072d74e315d12aeaa010611d622c6c81775d354aba1a1cda5f66b`).

### Reference metadata

`reference_metadata/` holds the NCBI Datasets metadata for each organism (`assembly_data_report.jsonl`, `dataset_catalog.json`, `data_summary.tsv`) and the build logs and `info.json` from the original salmon index (`salmon_index/`). `MD5SUMS` covers every file in this directory except itself.
